# IT202 Project Proposal - Emperor Gowdie

## Project Title
Golf Tournament Management

## Project Overview (Proposal)
This project is a PHP web application constructed to track every information in regards golf tournaments. Due to the use of CRUD operations and secure session handling It allows
users to register, log in, and manage their own participation in the golf tournaments. Users can view the existing tournaments, assign themselvesto the tournaments, and even remove their association with the tournaments as well. The admin users have the control in managing all tournaments, users, and the user tournament relationships. The purpose of this application was to integrate the Live Golf Data from RapidAPI in order to fetch real tournament data and even support custom tournaments. Overall, all three milestones have the capability to form a well functional web application.
